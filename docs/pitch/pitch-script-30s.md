# Pitch script: 30-second demo (Space Apps format)

Video: `docs/pitch/spherex-sky-motion-30s.mp4` (29.9 s). The English subtitles burned into the video are
exactly this text, at these times, so you can read along while recording. About 75 words.

| Time | Say (and the subtitle shows) |
| --- | --- |
| 0:00 | Hi! We are the SPHEREx Sky Motion team. *(or: “Hi! I'm [name], from team [team].” — ask Claude to re-render the subtitle)* |
| 0:02 | Our challenge: spot what moves in NASA's SPHEREx sky maps. |
| 0:05 | SPHEREx Sky Motion: watch the infrared sky move. |
| 0:10 | Pick a target: we play real SPHEREx images, one per six-month visit. |
| 0:14 | Subtract two visits: Barnard's Star moved north in one year. |
| 0:18 | Click a star for its spectrum, built from NASA data on the fly. |
| 0:22 | Next: anyone can hunt new brown dwarfs and asteroids, and every SPHEREx release adds frames. |

Pronunciation: SPHEREx = “sfear-ex”. Keep a steady pace; the last line has 8 seconds.

Re-render with names: `SPEAKER="Your Name" TEAM="Team Name" node scripts/record-demo-30s.cjs`
(needs `npm run dev` running and the targets opened once).
