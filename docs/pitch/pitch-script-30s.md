# Pitch script: 30-second demo (Space Apps format)

Video: `docs/pitch/spherex-sky-motion-30s.mp4` (29.9 s). The English subtitles burned into the video are
exactly this text, at these times, so you can read along while recording. About 60 words; each subtitle stays 4 to 6 seconds.

| Time | Say (and the subtitle shows) |
| --- | --- |
| 0:00 | Hi, I'm Mohamed Matrab, from team AstroSeekers. |
| 0:04 | For NASA's SPHEREx challenge, we built SPHEREx Sky Motion. |
| 0:10 | Pick a star, and the site plays every SPHEREx photo of it, six months apart. |
| 0:16 | Subtract two photos: Barnard's Star has moved north in one year. |
| 0:21 | Click a star to see its spectrum. |
| 0:25 | Now anyone can look for moving objects in NASA data. |

Pronunciation: SPHEREx = “sfear-ex”. Keep a steady pace; the last line has 8 seconds.

Re-render with names: `SPEAKER="Your Name" TEAM="Team Name" node scripts/record-demo-30s.cjs`
(needs `npm run dev` running and the targets opened once).
