## Project Name

SPHEREx Sky Motion

## High-Level Project Summary

SPHEREx Sky Motion is a public website that lets anyone watch the infrared sky change. You enter sky
coordinates or pick a suggested target, and it plays NASA SPHEREx images of that patch like a short
video, one frame per six-month visit. You can blink or subtract two visits to make moving objects stand
out, and click any star to build its spectrum on the fly from SPHEREx's 102 colours. It addresses the
“Planet X and SPHEREx” challenge: SPHEREx data are huge and technical, and spotting nearby stars, brown
dwarfs and asteroids by their motion is a task the public can help with. Every pixel is real archive
data, with its source.

## Detailed Project Description

**What it does.** Enter a right ascension and declination (any common format), an object name, or
one of five suggested targets (the challenge's test objects: Barnard's Star, WISE 0855, Epsilon Indi B,
RW Aurigae, R Draconis). The site finds every SPHEREx spectral image that contains that spot, downloads
small cutouts, places them on one north-up grid using each file's own sky coordinates, and:

- plays one averaged frame per survey visit (or every single image) like a video;
- blinks or subtracts two visits (white = brighter now, black = fainter now), which makes motion
  obvious. For Barnard's Star, August 2025 minus August 2026 shows it moving north by about ten
  arc-seconds, as its known proper motion predicts;
- builds a spectrum on the fly when you click a pixel: SPHEREx sees each spot at a different wavelength
  in every image, so all the images together give a spectrum, coloured by visit to reveal variability;
- overlays Gaia DR3 stars where their proper motion puts them on each frame's date;
- shows quality flags, removes the zodiacal glow with the archive's own model, and lists every source
  file;
- exports a captioned PNG or an animated GIF, and keeps the view in the URL so it can be shared or
  embedded.

**How it works.** A small Node.js server talks to NASA/IPAC IRSA: the TAP and SIA2 services for
the image list, and the cutout service for the images. It strips the large PSF table from each cutout
and caches them. The browser parses the FITS files itself (TypeScript), applies the TAN-SIP sky WCS and
the WCS-WAVE wavelength table, masks flagged pixels per the SPHEREx Explanatory Supplement, and draws
everything on a canvas. During the hackathon, IRSA's search service was down (error 502), so we also
built our own index of the five test targets. We scanned NASA's public SPHEREx archive on AWS and read
file headers directly; an image is kept only if the target falls inside it. The site uses it
automatically when IRSA's search is unavailable, and says so.

**Benefits.** No astronomy background is needed to see the sky move. Researchers and volunteers get a
fast first look, with provenance, before downloading full files. New SPHEREx releases appear
automatically.

**Tools.** TypeScript, React, Vite, Tailwind CSS, Node.js; gifenc for GIF export; Playwright for
testing and recording the demo. 31 automated tests run on a real SPHEREx file.

## NASA Data

- SPHEREx Level 2 spectral images (DR1 and Quick Release 3), NASA/IPAC Infrared Science Archive (IRSA):
  TAP, SIA2 and cutout services, https://irsa.ipac.caltech.edu/Missions/spherex.html
