# NASA Space Apps Challenge 2026 · Planet X and SPHEREx

Source of truth for our team's entry to the
[Planet X and SPHEREx](https://www.spaceappschallenge.org/2026/challenges/planet-x-and-spherex/?tab=details)
challenge (difficulty: advanced · astrophysics, planets & moons, software).

## The challenge in one sentence

Build a public web tool where anyone enters sky coordinates (right ascension and declination) and sees
SPHEREx images of that patch of sky played one after another like a short video, so that moving or
changing objects stand out.

## Ground rules

- Show only real archive data. Never invent, fill in or simulate a pixel, a position or a number.
- Every image says where it comes from: mission, data release, observation time, band.
- If data cannot be reached, say so. Never show a placeholder that looks like data.
- No discovery claims made by the tool or by AI: the tool helps people look; people and follow-up
  observations make discoveries.
